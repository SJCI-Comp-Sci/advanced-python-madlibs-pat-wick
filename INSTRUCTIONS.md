# Mad Libs

Build a Mad Libs game. Your program asks the user for several words, then drops
them into a silly story and prints the result.

## Requirements
- Collect **at least 4 words** from the user using `input()` (e.g. a noun, a
  verb, an adjective, a name).
- Collect **at least one number** and use it somewhere in the story (convert it
  with `int()`).
- Assemble the story using an **f-string**.
- Print the finished story.

## Steps
1. Accept the assignment and clone it into PyCharm.
2. Open `madlibs.py` and fill in your name and date at the top.
3. Write your program following the requirements.
4. Run it and test it a few times with different words.
5. Commit and push. Verify your code appears on GitHub.

## Grading
Program runs; collects at least 4 inputs and one number; uses an f-string;
prints a coherent story; code is readable with your name at the top.
